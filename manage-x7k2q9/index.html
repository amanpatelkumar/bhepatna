First-time setup

This stores your GitHub access token inside the website, encrypted with your password. Only someone with the password can use it. Do this once, right after publishing.

Reset password

We email a 6-digit code to the admin address. Then choose a new password and enter a GitHub token. The old token can't be read without the old password, so a new one is needed.
